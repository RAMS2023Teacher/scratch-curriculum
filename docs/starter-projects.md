# Starter projects to create

These lessons continue earlier work. Make each starter in your Scratch account, **Share** it, and paste its link on the **Lessons** page. Absent students then click **Remix** and start from there.

| Quest | Starter | It should contain |
|---|---|---|
| Clone Army | Catch Game starter | A Player sprite that moves left and right with the arrow keys at y -150. A Faller sprite with ONE green flag script: set score to 0, go to a random x at y 170, then a forever loop with change y by -5, an if touching Player that adds 1 to score and goes back to the top, and an if y position less than -170 that takes away 1 point and goes back to the top. A score variable For all sprites. |
| Scene Changer | Animated Story starter | Two character sprites named Character A and Character B, one backdrop named scene1, and a 6-line conversation that uses broadcast messages line 2 to line 6. The last line (line 6) is said by Character B in a when I receive [line 6] script. Each character has a green flag script with go to x: y:. |
| Quiz Builder | Quiz App starter | A sprite named Bot. Its chatbot script from a1 (ask, join, if else) may be there, but its hat block is changed to when c key pressed so it does not run on the green flag. No score or question variables yet. |
| Level Up! | Platformer starter | A backdrop named level1 with a ground and platforms in one color. A Player sprite with two green flag scripts: a walk script (go to x -200 y 0, then a forever loop with left and right arrow keys) and a gravity script (y speed For this sprite only; change y speed by -1 and change y by y speed; if touching the platform color, move back by 0 minus y speed, set y speed to 0, and jump with the up arrow by setting y speed to 14; if y position less than -170, go to x -200 y 0 and set y speed to 0). |
| Sound and Atmosphere | Interactive Adventure starter | Backdrops named start, cave, forest, treasure, and home; a Narrator sprite; Choice A and Choice B button sprites that hide on the green flag and show or hide on the messages show choices and hide choices; a scene variable (For all sprites); and Narrator scripts for the messages go cave, go forest, go treasure, and go home. forest, treasure, and home are endings. |
| Drawing Tools | Super App (from List Master) | A Host sprite with the green flag flashcard script (card variable, questions and answers lists For all sprites with 5 cards each, review list), and an Add Card button sprite. |
| Playtest & Polish | Polish Starter | A finished catch game from the teacher: a Cat player that moves with the arrow keys, an Apple that falls from the top, a score variable, and green flag scripts that reset everything (score to 0, positions, costumes). It has NO title screen, NO instructions, and one small bug (the Apple sometimes starts too low). Students who missed a project can polish this one. |
| Capstone Build | Capstone Skeleton | For option C or absent students. The teacher's skeleton has: a Player sprite with a green flag script that goes to a start spot and moves with the arrow keys; an empty Title sprite with the safe title script from Playtest & Polish (show, wait until space is pressed, hide); a score variable and a time variable (For all sprites) set to 0 on the green flag; two backdrops named level 1 and level 2; and empty "when I receive game over" and "when I receive next level" scripts on the Stage. It uses only trunk skills, so it works for every path. |
| Showcase Day | Capstone Skeleton | For absent students: the same skeleton as Capstone Build (a Player that moves with the arrow keys, a Title sprite, score and time variables, two level backdrops). A student who missed Capstone Build adds one feature to it and showcases that. |

## Other prep before you start

- **Class studio** on Scratch: students add every shared project. It is used for the Code Reader step in Bug Hunters (m1) and the gallery walk on Showcase Day (f3).
- **Mystery Bug project** (m1 solo option): a small project with one hidden bug, for students with no partner free to swap with.
- **Teacher example project** (m1 Code Reader solo option): any working project from another branch that students can See Inside.
- **Student Scratch accounts**: confirm the accounts can Share. New accounts need a confirmed email or a teacher-created class account.
- **Headphones** for read-aloud and for the sound lessons.
