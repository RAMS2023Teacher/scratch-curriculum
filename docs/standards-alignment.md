# Scratch Quest: MA DLCS Standards Alignment

Massachusetts Digital Literacy and Computer Science Curriculum Framework (2016), Grades 6–8. Standard text is quoted from the official framework: https://www.doe.mass.edu/frameworks/dlcs.pdf

Each student completes 14 of the 22 quests (the trunk, one branch at each fork, the rejoin quests, and the finale). Branch quests are marked with their path.

## By lesson

| Tier | Quest | Path | Standards (grades 6–8) | Practices |
|---|---|---|---|---|
| 1 | Hello, Sprite! | Sprite Meadow | **6-8.CT.d.3**: Builds scripts that move, turn, and glide a sprite to target spots.<br>**6-8.CT.b.2**: Predicts where a sprite lands from its x and y values (quick check).<br>**6-8.CAS.a.3**: Shares a public project using first name only and no personal info. | Creating, Connecting |
| 2 | Lights, Camera, Events! | Sprite Meadow | **6-8.CT.d.5**: Sequence detective: swaps two blocks and traces what changes.<br>**6-8.CT.d.3**: Uses event blocks (green flag, keys, clicks) to start scripts. | Creating, Analyzing |
| 3 | Loop-de-Loop | Sprite Meadow | **6-8.CT.b.1**: Uses repeat and forever loops for motion and animation.<br>**6-8.CT.d.1**: Compares the copy-paste "long way" with the loop way.<br>**6-8.CT.b.4**: Solves the same square path two different ways.<br>**6-8.CT.d.4**: Looping behavior. | Creating, Abstracting |
| 4 | If This, Then That | Sprite Meadow | **6-8.CT.b.1**: Combines a forever loop with if blocks for maze controls and walls.<br>**6-8.CT.d.4**: Conditional statements and sensing (touching color).<br>**6-8.CT.d.6**: A neighbor playtests the maze, then the student fixes one thing. | Creating, Collaborating |
| 5 | Power-Up Pack | Sprite Meadow | **6-8.CT.d.4**: Variables, comparisons, if/else, and broadcasts in one virtual-pet program.<br>**6-8.CT.b.1**: A forever loop with if/else decides the pet's mood.<br>**6-8.CT.b.2**: Predicts results of set vs. change, and of comparisons like 4 < 4.<br>**6-8.CT.b.5**: Caps energy at 10 and stops at 0, handling the edges of the value. | Creating, Abstracting |

| 7 | Scene Changer | Story Woods | **6-8.CT.b.3**: Splits the story into three scenes and codes each one.<br>**6-8.DTC.b.1**: Publishes a multi-scene animated story.<br>**6-8.CT.d.6**: Watches the story twice to check that it resets correctly. | Creating, Communicating |
| 7 | Quiz Builder | Gadget Bay | **6-8.CT.b.3**: Breaks the quiz app into buttons, question tracking, and a results screen.<br>**6-8.CT.d.4**: Score and question variables with conditional answer checks.<br>**6-8.DTC.b.1**: A quiz that informs users about a topic the student knows. | Creating, Communicating |
| 8 | Bug Hunters & Code Readers | Debug Caves | **6-8.CT.d.5**: Traces four buggy scripts block by block, then reads and explains an unfamiliar classmate project.<br>**6-8.CT.b.2**: Code Reader: predicts what a change will do before running it.<br>**6-8.CT.d.6**: Uses a test, change, test-again debugging cycle.<br>**6-8.CS.a.7**: Follows a step-by-step troubleshooting routine and writes a bug report. | Analyzing, Collaborating |
| 9 | My Blocks Workshop | Debug Caves | **6-8.CT.a.2**: Makes reusable custom blocks such as dance and square of any size.<br>**6-8.CT.d.2**: Hides repeated detail inside My Blocks.<br>**6-8.CT.d.4**: Functions with inputs. | Abstracting, Creating |

| 10 | List Master | Gadget Bay | **6-8.CT.c.3**: Builds a small list "database" and adds new records (cards) from the app.<br>**6-8.CT.a.1**: Represents a flashcard by its attributes: question and answer.<br>**6-8.CT.d.4**: Lists with loops and a variable that counts through cards. | Abstracting, Creating |
| 11 | Level Up! | Arcade Peaks | **6-8.CT.b.3**: Breaks the game into levels, doors, lives, win/lose screens, and high score.<br>**6-8.CT.d.4**: Variables for lives, score, and high score.<br>**6-8.CT.d.6**: Playtests the whole game from start to finish. | Creating, Analyzing |
| 11 | Sound and Atmosphere | Story Woods | **6-8.DTC.a.3**: Combines recorded audio, music, sound effects, and images in one project.<br>**6-8.DTC.b.1**: Uses sound and visual effects to set mood and entertain. | Creating, Communicating |
| 11 | Drawing Tools | Gadget Bay | **6-8.CT.d.3**: Builds a working paint tool from a goal (brush, colors, sizes, clear).<br>**6-8.CT.b.3**: Breaks the app into Study and Sketch modes with a menu.<br>**6-8.CT.d.4**: Variables and conditionals for brush settings. | Creating, Abstracting |
| 12 | Playtest & Polish | Showcase Castle | **6-8.CT.d.6**: Turns playtest feedback into a fix list, then fixes and retests.<br>**6-8.DTC.b.1**: Writes instructions and credits so others can use the project. | Analyzing, Collaborating, Communicating |
| 13 | Capstone Build | Showcase Castle | **6-8.CT.b.3**: Breaks an example game into features and blocks with the class, then decomposes their own idea the same way.<br>**6-8.CT.d.3**: Builds a program toward a stated goal: the MVP.<br>**6-8.CT.d.4**: The challenge combines loops, conditionals, variables, and a custom block. | Creating, Analyzing |

## Not covered by this unit

Computing Devices (except troubleshooting, CS.a.7), Networks, Services, Human and Computer Partnerships, Research, data representation (binary), most of Ethics and Laws (copyright, fair use, licensing), and Interpersonal and Societal Impact. These need lessons outside a Scratch programming unit.
