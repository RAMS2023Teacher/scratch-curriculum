# Scratch Quest lesson feedback

6th grade: Scratch · 2026-11-18 · 12 students in Period 3 · Demo Class · student names removed

Please use this to improve the lessons in the Scratch Quest repository. Each lesson is a JavaScript file (path given) in the `SQ_LESSONS.<id> = {...}` format described in `docs/LESSON_SPEC.md`; run `node tools/validate.js` after editing. Steps are numbered the way students see them (Step 1 = the first build step; optional "stretch" steps are marked). Quiz "missed" counts first tries only. Saved progress is stored by step position, so change a step's content in place rather than inserting or removing steps.
