# Scratch Quest: Accommodation & Differentiation Plan

This plan lists the supports built into Scratch Quest and how to use them for specific students. Each lesson's **teacher notes** (Lessons tab → Preview) also has a short accommodation note for that lesson.

## Built into every lesson (all students)
| Support | What students see |
|---|---|
| **One card at a time** | One step per screen, so a student never faces a full page of instructions. |
| **Short instruction first** | Each step leads with one plain sentence (about 10 words). The full explanation is folded under **📖 Tell me more**. |
| **🔊 Read to me** | Reads the card aloud with the browser's built-in voice. It works offline. Students need headphones. |
| **📸 Where to look** | Real Scratch screenshots with the exact button circled. Tap one to see it bigger. |
| **🎭 On / ✨ NEW / 🔁 REPLACE labels** | Every code step says which sprite the code goes on, and whether it is a new script, an addition, or a replacement. |
| **Fading support** | Each lesson moves from full scripts, to 🧩 block puzzles (blocks shown shuffled), to 🎯 build-it-yourself. **Stuck? Show me** is always one tap away, so no one is left stuck. |
| **💡 Hints** | Each hint covers the most common mistake at that step. |
| **Core vs ⭐ Stretch** | Only core steps are needed to turn in. Stretch steps are marked "If you have time" and can be skipped. |
| **✏️ Writing frames** | Every writing task (dialogue, story map, bug report, Glow & Grow, plan, pitch, reflection) comes with sentence frames and a Copy button. |
| **📖 Word bank** | Picture-cue vocabulary in simple English, with no idioms. |
| **🆕 Primer cards** | If a student's path skipped a skill (for example a Stories student meeting ask/answer), a short primer card appears before that lesson. |
| **👤 Solo options** | Every partner step has a "No partner free right now?" alternative. This matters because students work at their own pace. |
| **✅ Turn-in checklist** | 3–5 "My project has…" items, so students know what "done" means. |
| **Self-paced** | No timer. A student can take two class periods on one quest. |

## Per-student settings (Teacher → Dashboard → click a student → 🧩 Accommodations)
- **Core steps only**: hides stretch steps and the expert challenge. Use it for students with IEP/504 plans for reduced workload or chunking, and for anyone who is overwhelmed.
- **Read each card aloud automatically**: for students with reading IEPs or dyslexia, and newcomer English learners.
- **Private note**: a reminder for you, such as "extended time" or "check in at step 3". Students never see it.

## By student need
**Struggling readers / dyslexia:** turn on auto read-aloud. Encourage the screenshots and block pictures over the "Tell me more" text. Pair the student with a reading buddy only for the warm-up.

**Students with IEPs/504s (attention, executive function):** Core steps only. Use the dots row as a visual schedule ("you're on dot 4 of 7"). Check in after the first 🎯 build-it-yourself step. Accept a verbal explanation in place of written reflections.

**Fine motor difficulties:** for painting steps (t3 sprite, t4 maze, title screens), allow library sprites and backdrops, or a teacher-made maze backdrop. Allow keyboard nudging instead of dragging.

**English learners:** auto read-aloud (Chrome can read in English while students follow the text), picture vocabulary, writing frames, and screenshots. Allow first-language planning on paper. Block pictures are language-neutral. Scratch itself can be switched to the student's language with the 🌐 menu.

**Absent or behind:** every "part 2" lesson has a **🧳 starter project** link (add the links on the Lessons page). An absent student remixes the starter and continues without the lost work. The pacing gate (Classes tab) keeps the class within a range. The progress grid shows who is stuck where.

**Advanced students:** ⚡ expert challenges are spec-only (no blocks given). They can go back and complete other branches (Explorer badge). Teacher badges reward helping others (Helping Hand).

**Students anxious about presenting (f3):** they can present to the teacher only, record a screen video, or type their pitch.

**No microphone (s4 voice recording):** use a library sound or text-to-speech in a speech bubble.

## Assessment adjustments
- Grade on the **core checklist**, not stretch steps or challenges.
- The quick checks allow retries. Watch "first try" on the student page to spot students who are guessing.
- The f3 Mystery Mission (a 10-minute independent build) is the transfer check. Accept partial builds with a verbal explanation.
